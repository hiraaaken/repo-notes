# Repo Notes アプリ ユースケース一覧

ペルソナモデルとユーザー行動シナリオを起点に、タスクを洗い出し、ユースケースとして整理する。

---

## 1. ペルソナモデル

`hiraaaken/base` を Zettelkasten として運用する個人ナレッジワーカー。

| 項目 | 内容 |
|------|------|
| 役割 | 個人開発者・ナレッジワーカー（1 人ユーザー） |
| ゴール | 思考・読書・調査メモをモバイルで即時キャプチャし、PC でのレビュー・整理ループを維持する |
| 現在の課題 | Notion 併用で二重管理が発生。モバイルから `hiraaaken/base` へ直接書けない |
| 利用端末 | Android スマートフォン（主）、PC（Zettelkasten 編集・Claude Code） |
| ネットワーク環境 | 自宅 WiFi（安定）、移動中はモバイル回線または圏外 |

---

## 2. ユーザー行動シナリオ

### S-01: 朝のレビューシナリオ

起床後、アプリを開く。起動時 fetch が走り、昨夜の `/schedule` バッチが処理したノートが自動取得される。ノートタブで新しい literature / permanent ノートを確認し、今日の学習テーマを把握する。

### S-02: 移動中のメモキャプチャシナリオ

電車・カフェ等で思いついたアイデア、読書中の気づき、あとで調べたい事項をメモタブの FAB から即入力する。genre を選び、タグを頻度順チップから選択して保存する。オンラインであれば即座に `daily.md` へ append commit される。

### S-03: オフライン時のメモシナリオ

地下鉄や機内など圏外でも S-02 と同じ操作でメモを書く。アプリはローカルキューに積み、メモカードに「同期中」バッジを表示する。WiFi 復帰後、バックグラウンドで自動リトライされ、バッジが消える。

### S-04: 同期トラブルシナリオ

「ノートが古い気がする」「PAT 期限切れかも」と感じたとき、設定タブを開いて最終 sync 時刻とエラー文を確認する。PAT 期限切れが原因なら新しい fine-grained PAT を入力し、手動 sync ボタンで即座に回復する。

### S-05: 初期セットアップシナリオ

アプリ初回起動後、設定タブで `hiraaaken/base` の Contents R/W 権限を持つ fine-grained PAT を入力する。入力後、初期 fetch が走りノートが端末に取り込まれる。

## 3. タスクの洗い出し

タスク = ユーザーまたはシステムが「何かを達成するために行う最小単位の操作」。
想定業務（`design.md`）と行動シナリオの両方から抽出する。

### 3-1. 想定業務から読み解くタスク

## 4. 概念オブジェクト

このアプリで扱う主要な概念オブジェクトを整理する。

| オブジェクト | 説明 | ソース・オブ・トゥルース |
|------------|------|----------------------|
| **Note（ノート）** | `hiraaaken/base` リポジトリ内の Markdown ファイル。kind（fleeting / literature / permanent / research）・タグ・本文を持つ | GitHub リポジトリ（ローカル DB はキャッシュ） |
| **Memo（メモ）** | ユーザーがアプリから書く短文メモ。genre・tags・created・本文を持ち、`daily.md` に append される | ローカル端末（`memo_queue` → GitHub へ送信） |
| **Tag（タグ）** | ノートとメモの両方に付くトピックラベル。大小文字は保持。出現頻度でソートされ chip 表示される | GitHub リポジトリ（`tags` テーブルは派生） |
| **Genre（ジャンル）** | メモの意図分類。`idea` / `reading` / `investigate` の 3 値 enum。`/schedule` バッチへのヒント | アプリ定義（固定 enum） |
| **SyncState（同期状態）** | 最終 fetch のコミット SHA・時刻・エラー文。設定タブに表示される | ローカル端末（`sync_state` テーブル） |
| **MemoQueue（送信キュー）** | 未送信・失敗メモの待機リスト。オフライン時に積まれ、復帰後に flush される。`dedup_key` で重複防止 | ローカル端末（`memo_queue` テーブル） |
| **PAT（Personal Access Token）** | GitHub fine-grained PAT。`hiraaaken/base` の Contents R/W のみ許可。OS Keystore に暗号化保存される | ローカル端末（flutter_secure_storage） |
